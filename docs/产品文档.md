# 记账 app — 产品文档

> 版本：v0.2
> 日期：2026-09-09

---

## 1. 产品定位

一款**本地桌面记账应用**，运行在 Windows 和 Mac 电脑上，帮助用户记录和管理每一笔人民币收支（支出 + 收入）。

- 单机使用，数据存在用户自己的电脑上（不上传网络）。
- 面向个人/家庭日常记账，操作简单。

## 2. 核心功能（第一版必须做）

| 功能 | 说明 |
|------|------|
| 记一笔支出 | 输入金额（人民币）、选择分类、填备注，自动记录日期 |
| 记一笔收入 | 输入金额、选择收入分类、填备注（可选） |
| 二级分类 | 每笔账归属「一级大类 → 二级小类」（支出、收入各一套） |
| 收支列表 | 按时间倒序展示所有账目，可按日期/分类查看 |
| 统计 | 查看某月总支出、总收入、按分类汇总、占比图 |
| 编辑 / 删除 | 修改或删除已记的账 |

## 3. 后续可选功能（第一版先不做，以后可加）

- 预算提醒（设置每月预算，超支提醒）—— 用户确认暂不做
- 搜索、导出 CSV / Excel
- 数据备份与恢复
- 深色模式

## 5. 数据模型（草案，技术实现时再细化）

- **一笔账目记录**：类型（支出/收入）、金额（元，保留2位小数）、一级分类、二级分类、备注、日期时间。
- **分类表**：类型（支出/收入）、一级大类、二级小类，支持后续增删改。
