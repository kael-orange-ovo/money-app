## 1. 整体布局：左侧导航

- 左侧竖排导航栏，包含：**记一笔、账单、统计** 三个入口（顶部显示 App 名称）。
- 右侧是内容区，随左侧选中项切换。

```

│ 记账app   │  内容区（随左侧切换）      │

│ │记一笔│  │                         │
│ ├─────┤  │                         │

│ │ 统计 │  │                         │
│ └─────┘  │                         │

```

## 2. 三个页面

### 2.1 记一笔（默认打开页）

- 顶部：**支出 / 收入** 两个切换按钮。
- 金额：大号数字输入框（人民币，最多两位小数）。
- 分类：**先选一级大类，再选二级小类**（两个选择区，或"大类→小类"联动）。
- 备注：可选填文本框。
- 日期：默认今天，可改。
- 底部：**保存** 按钮。

### 2.2 账单（列表）

- 顶部：**月份切换**（← 2026年9月 →）。
- 汇总卡片：本月**总收入**、**总支出**、**结余**。
- 列表：按**日期分组**（同一天归到一起），每条显示：分类图标 + 二级分类名 + 备注 + 金额。
  - 支出金额显示为红色 `-¥25`，收入显示为绿色 `+¥8000`。
- 每条支持 **编辑 / 删除**（点击或右键）。

### 2.3 统计

- 顶部：月份切换。
- **分类占比**：饼图或环形图，展示当月各一级大类的支出占比。
- **分类排行**：从高到低列出各分类金额。
- （后续可加：收入统计、月度趋势折线图。）

## 3. 视觉风格：浅色清爽

- 主背景：白色 / 浅灰。
- 主色调：清新的蓝色（按钮、选中态）。
- 支出：红色；收入：绿色。
- 圆角卡片、留白充足，风格简洁。

> 具体颜色值在写代码时定，会先给你看效果图再确定。

## 4. 交互补充

- 记账保存后：自动回到"账单"页并刷新，或弹出"保存成功"提示。
- 所有操作尽量少的步骤：记一笔 = 选类型 → 填金额 → 选分类 → 保存（备注、日期可跳过）。
